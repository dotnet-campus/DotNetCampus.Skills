# Awesome dotnet-campus skills

## ai-code-cleaner - AI 常见犯浑代码清理

审查仓库（或指定范围）中 AI 生成代码常见的各类问题，将发现记录到 Markdown 报告中，并协助人类安全地修复。

## architecture-plan-review - 计划文件架构遵循性审查

审查计划文件的架构遵循性，按架构模块边界彻底重组计划文档结构。适合那些可能破坏代码架构的任务，确保 AI 在计划和执行阶段遵循架构设计和原则约束。

## dotnet-source-generator - AI 从容应对源生成器项目

帮助 AI 理解和开发 .NET/C# 源生成器（Source Generator）项目。涵盖源生成器的开发、调试、验证生成输出等关键环节。
